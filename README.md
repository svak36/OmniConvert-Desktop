## English

OmniConvert brings practical file tools into one desktop workspace. Work with images, PDF documents and audio using tools installed on your computer.

### Why OmniConvert?

- **Local file processing:** supported local tools work on your device rather than uploading files to a cloud conversion queue.
- **Modular toolkit:** download the tools you need and remove unused tools. Removing a tool does not delete your files.
- **One workspace:** browse the tool catalog and manage installed tools in a focused interface.
- **Windows and macOS:** downloads are available for Windows x64 and Macs with Apple Silicon.

An internet connection is required to download tools and updates. Available tools and format support depend on the installed tool and application version.

## Русский

OmniConvert объединяет инструменты для работы с файлами в одном настольном приложении. Работайте с изображениями, PDF-документами и аудио с помощью инструментов, установленных на компьютере.

### Что удобно

- **Локальная обработка:** поддерживаемые локальные инструменты работают на устройстве, без отправки файлов в облачную очередь конвертации.
- **Модульная система:** скачивайте нужные инструменты и удаляйте неиспользуемые. Удаление инструмента не удаляет ваши файлы.
- **Единое рабочее пространство:** каталог инструментов и управление установленными инструментами в одном интерфейсе.
- **Windows и macOS:** доступны загрузки для Windows x64 и Mac с Apple Silicon.

Для скачивания инструментов и обновлений нужен интернет. Доступные функции и форматы зависят от установленного инструмента и версии приложения.
